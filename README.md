### Nasıl Katkıda Bulunabilirsiniz?

1. **🍴 Fork yapın** - Projeyi kendi hesabınıza kopyalayın
2. **🌿 Branch oluşturun** - `git checkout -b feature/harika-ozellik`
3. **💻 Kodlayın** - Yeni özellik veya düzeltme ekleyin
4. **✅ Test edin** - Değişikliklerinizin çalıştığından emin olun
5. **📤 Push yapın** - `git push origin feature/harika-ozellik`
6. **🔄 Pull Request açın** - Değişikliklerinizi bizimle paylaşın
